# Minigame 1
## Devlog
After completing this level, I realized that Scenes are like a complete set of stage decorations, while Game Objects are the various elements placed within that scene. Components, on the other hand, refer to the rules that govern these elements. For example, platforms, coins, and spikes are all game objects, but they alone dont tell us what they can do. Their Transform properties determine their position within the scene, while Collider properties determine what objects they can touch.Scripts, then, dictate how these objects behave. A scene is essentially the environment that players actually experience. Changing a game object changes this environment, and adjusting or maintaining its components determines whether it remains a usable platform, collectible item, or dangerous element.

I understood this better when designing the path. I created and duplicated platforms to form steps, and tried to play the game along that path, rather than relying solely on the scene view. When duplicating coins, I noticed that the coin located beneath another coin had a local position; therefore, the values I entered didnt place it in the correct location as expected. The spikes taught me another lesson: once spikes are placed on a platform, that path becomes unusable, although the spikes themselves can still be used normally. I had to move the spikes until players could find a way around them, and then test whether they reappear after being touched. These changes helped me realize that a playable scene is determined by how each object is positioned and the components that make them react to each other.
